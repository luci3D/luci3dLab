# The maze zine

The original hand-drawn maze puzzles that the luci3D snake logo comes from. They are the proof-of-concept levels for the game and the reference for the FC city's look (long parallel corridors, 45-degree cuts, spirals: they already look like PCB routing).

| File | Notes |
|---|---|
| `maze-01.png` | Filled triangle left, hollow triangle right; a large solid block in the centre; a circle |
| `maze-02.png` | Hollow triangle top right, filled triangle bottom left; long 45-degree cuts; solid wedges |
| `maze-03.png` | Hollow triangle right, filled triangle left; diagonal hatch areas; a "+" and a boxed diagonal |
| `maze-04.png` | Filled triangle top left, hollow triangle bottom right; a spiral; a circle with an opening |
| `maze-05.png` | Hollow triangle top, filled triangle right; two long diagonals that cut the maze; an "X" |

## Legend

| Symbol | In the game |
|---|---|
| Triangles on the outer edge | Entry and exit |
| Solid black blocks | Story assets: places where a piece of the story is told |
| Circle, X, + | Power-ups or items (to be decided) |
| Lines, including the diagonals | Walls (traces you can't cross) |

Still open: which triangle is the entry and which is the exit (filled = entry, hollow = exit is the working guess), and what each item does.
